## What's new in 2.30.2

### Fixed
- **A fresh installation works again.** Installing Ticketstation on a new site failed with the error *Column count doesn't match value count at row 1* in 2.29.0 up to 2.30.1. Updating an existing site was never affected.

### Improved
- **The administration fits on a phone.** The Box Office, Coupons, Invoicing, Transactions, Waiting list and Seat plans screens no longer run off the screen on a small display: table headings wrap, long words break and the links above the lists wrap.
- **The scanner's events and tickets list stays inside the screen** on a phone. The notes under Event and Ticket wrap instead of making the table wider than the screen.
- **The Edit seat plan button** is an icon on a phone, and the Venue column of the seat plan list is hidden there, like in other lists.
