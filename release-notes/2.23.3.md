## What's new in 2.23.3

### Fixes
- **No more PHP 8.4 deprecation notices in the administrator.** On PHP 8.4 every administrator page showed "Implicitly marking parameter ... as nullable is deprecated" messages; those are gone. Nothing changes on older PHP versions.
- **Higher ticket prices can be entered.** The *Price per ticket* field no longer stops at 5 characters, so prices such as 2600000 can be saved, for currencies with large nominal values.
