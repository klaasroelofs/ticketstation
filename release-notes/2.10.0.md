## What's new in 2.10.0

### Security
- **Updated PDF library.** The library that makes the ticket PDFs (FPDI) is updated to fix two known security issues, in which a malformed PDF could make the server run out of memory or hang. The QR code library is updated as well. Tickets, the ticket preview and invoices look exactly the same as before.

### Coupons
- **A coupon stays with the cart.** A customer who removes every ticket from the cart and then adds tickets again keeps the coupon they entered. Before, the coupon disappeared together with the last ticket.

### Extensions screen
- **Clear description.** In *System* › *Manage* › *Extensions*, the Ticketstation component and package now describe what Ticketstation does, in English and in Dutch.

## Check before you update
- **Database changes.** This update moves the coupon of an order to the table that holds the order totals and removes database columns that Ticketstation no longer used. Existing coupons are moved automatically, and the Box Office, invoices and coupon usage stay the same. Only if you run your own reports or queries directly on the Ticketstation tables should you check that they still work.
