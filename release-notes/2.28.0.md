## What's new in 2.28.0

### New
- **Pay with Stripe.** Stripe is now included next to Mollie. The customer pays on Stripe's own payment page, which shows the methods you switched on in your Stripe Dashboard (cards, iDEAL, Bancontact and more). Refunds from the Box Office work, and refunds and disputes made in the Stripe Dashboard are picked up: a dispute shows up as a chargeback that waits for your decision about the tickets. The Stripe plugin is installed switched off, so nothing changes for a shop that uses Mollie. To use it, switch it on under **Payments**, enter your Stripe keys and register the webhook address from its settings in the Stripe Dashboard.
- **Step-by-step help for Stripe.** The *Online payments* topic of the Documentation now explains how to set up a Stripe account, find the keys and register the webhook, and how to check that it works.
- **Build your own payment plugin.** The Documentation explains how to add another payment provider as a plugin, and points to the guide and an example plugin in the Ticketstation repository on GitHub.

### Improved
- **The payment documentation treats Mollie and Stripe alike.** Each has its own section for the account and the settings, and the rest of the Documentation speaks of "the payment provider" instead of Mollie.
- **The warnings for Mollie on the control panel say Mollie.** The messages about a missing, invalid or test key now name the provider, as the Stripe ones do.
- **Payment methods have proper names.** The Transactions screen shows the same names as the Box Office, for example *iDEAL* instead of *Ideal*.
- **Seats are sorted in `{orderlist}`.** The seats of an order appear in order in your mails, and the preview of a template shows a realistic example.

### Fixed
- **The ID of a refund or chargeback is shown again.** Since version 2.25.0 it was missing in the order and on the screen where you decide about the tickets.
- **Refunds that are still waiting at the payment provider are checked again.** Opening an order looks them up at the provider, so the tickets change as soon as the provider has processed the refund. Since version 2.25.0 this no longer happened.
- **A refund made in a provider's dashboard is labeled correctly.** It said *Made in the Box Office* for every provider except Mollie; it now says *Made at the payment provider*.
