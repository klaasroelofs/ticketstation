## What's new in 2.29.0

### New
- **One switch for test mode.** Test mode is no longer a setting of each payment plugin. On the control panel, next to the heading of the sales figures, a **Shop mode** switch reads *Live* or *Test* (amber in test mode). In test mode the shop is closed to the public, tickets are marked as test tickets, and the payment provider uses its test environment. Switching back to *Live* makes the provider use its live keys again. You can no longer leave the shop in test mode while the provider is live, or the other way round. Hover over the switch for an explanation; only Administrators can use it.
- **Mollie and Stripe follow the shop.** They use their test keys while the shop is in test mode and their live keys otherwise. The Test Mode setting is gone from both plugins. In test mode the control panel warns when the test key of your provider is missing.
- **Providers without a test environment.** A payment plugin from another developer may have no test environment. While the shop is in test mode, paid orders are not sent to such a provider, because that would be real money. The order is refused with a clear message, the control panel shows a warning next to the switch, and free tickets can still be tested.
- **For plugin developers.** The developer guide has a new section on test mode, and the example plugin shows how a provider follows the shop.

### Improved
- **Test mode also applies when online payments are off.** The shop is then closed to the public as well, and free tickets are marked as test tickets.
- **The Payments screen shows whether the shop is in test mode,** with a link to the switch.

### Fixed
- **No promise of tickets by email when tickets are not sent directly.** With *Send tickets directly* switched off, the payment result page no longer says the tickets are on their way by email and no longer offers downloads; it says the tickets follow later.

## Check before you update

- **Test mode moved to the control panel.** A shop whose payment plugin was in test mode keeps test mode on after the update. After updating, check the **Shop mode** switch on the control panel and set it to *Live* when sales are open.
- **Payment plugins from other developers** that have their own Test Mode setting keep working, but while the shop is in test mode they receive no paid orders until their developer has updated them to follow the shop's test mode (see the developer guide).
- **Refunds in test mode.** While the shop is in test mode, payments that were made in live mode cannot be refunded from the Box Office, because the provider's test environment does not know them. Switch to *Live* first.
