## What's new in 2.23.1

### Fixes
- **New installations work again.** Installing Ticketstation 2.23.0 on a site that did not have it yet failed with "Column count doesn't match value count at row 1". The default settings that are added on a first install did not match the tables anymore. Sites that updated to 2.23.0 were not affected.
- **Release notes after an update.** The notes of a release are now shown as a message after installing or updating, instead of staying out of sight.
