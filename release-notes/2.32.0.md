## What's new in 2.32.0

### Reservations
- **Fill in the Order Reference while making a reservation.** Step 3, *Customer details*, has an optional *Order Reference* field. It is shown in step 4 and saved with the order, so it is in the Box Office straight away and printed on the tickets when the ticket design has an order reference, also when the reservation is paid right away.

### Changed
- **The Order Reference is called that everywhere.** The messages when you add, change or remove it in the Box Office, and the descriptions of the permissions, still spoke of a "remark". They now say *order reference*. The note a customer adds in the cart keeps its own name.

### Fixed
- **Removing tickets without a seat works in the reservation tool.** The × next to a ticket type without a seat did nothing. It now removes all tickets of that type from the reservation.

## Check before you update
- **The Order Reference has moved to a renamed database table.** The update renames `#__ticketstation_remarks` to `#__ticketstation_order_references` (column `order_reference`) and keeps every reference. Only if you have your own reports or code that read the old table do you need to change them.
