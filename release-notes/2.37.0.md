## What's new in 2.37.0

### Ticketstation on Joomla's dashboard
- **Widgets for the Home Dashboard.** The new module *Ticketstation Dashboard* puts parts of the Control Panel on the page you land on after logging in to the backend. One module shows one widget, so you make a module for each widget you want, in the position *cpanel*. The widgets are:
  - *Needs attention* (the same list as the Control Panel, urgent items first)
  - *Key figures* (sales of this week and this month, what is on sale and the chart of the last four weeks)
  - *Upcoming events* (the next tickets with how many are left)
  - *Quick links*
  - *Door today*
  - *Latest orders*
- **Quick links** You choose the links and drag them into the order you want. *Events* and *Tickets* have a plus button to add one directly, and the *Box Office* button shows a counter with what needs attention there: the same number as on its button in the Control Panel. The scan page opens in a new tab.
- **Door today.** On the day of an event it shows, for each event that is today, how many valid tickets are sold, how many are scanned, how many are still to come and the time of the last scan. The numbers refresh every half minute while the dashboard is open. Without an event today the card is not shown.
- **Latest orders.** The latest paid orders with the customer, the event, the number of tickets and the total, each linking to the order in the Box Office.
- **A bar while the shop is in test mode.** The new module *Ticketstation Test Mode* shows a bar at the top of the backend pages saying that Ticketstation is in test mode, so a test mode that was left on by mistake is noticed. It is left out on the Ticketstation screens themselves, which show test mode on their own; a setting of the module changes that.
- **Every widget can have its own title and icon,** like Joomla's own modules. Titles that start with *Ticketstation -* make the cards easy to recognise.
- **The Control Panel itself is the same as before.** Its figures now come from the same source as the widgets, so both always agree. The Documentation has a new section, *Ticketstation on Joomla's dashboard*, in the Control panel topic.

## Check before you update
- **An update does not place any module.** Add the widgets you want on Joomla's dashboard with *Add Module to the Dashboard*, or under *System » Administrator Modules* with *New* and *Ticketstation Dashboard*. Add *Ticketstation Test Mode* in the position *top* if you want the bar. A new installation starts with *Needs attention*, *Key figures* and *Quick links* on the dashboard and the bar in place.
- **Door today and Latest orders show names and amounts,** so only users who may work with the Box Office (the permission *Box Office*) see them. The other widgets are shown to everyone who may open Ticketstation.
- **The key figures on the dashboard are kept for two minutes,** because they are the heaviest part of it. The Control Panel itself is not cached.
- **There are no database changes** in this release.
