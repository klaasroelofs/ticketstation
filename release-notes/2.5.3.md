## What's new in 2.5.3

### New menu item types
- **Single ticket** links straight to one ticket: seated tickets open the seat chart, other tickets open the ticket page.
- **Lost tickets** lets customers request their tickets again by entering their email address. They receive one mail per paid order for an event that hasn't ended yet, the same mail as the *Resend* button in the Box Office. The page gives the same answer whether or not anything is found, sends at most one copy per order every 15 minutes, uses the site's default captcha when one is set, and notes each copy in the order history.
- All Ticketstation pages (ticket pages, cart, checkout, payment result and the links in mails) now sit under the *Show Upcoming events* menu item, instead of under whichever Ticketstation menu item was created first. So a *Ticket scanning* or *Single ticket* item no longer takes over the shop.

### Ticket layout
- New field **Venue**: prints the venue name and city on the ticket, e.g. *Riverside Theatre, Amsterdam*. "Load Values" copies it from another ticket, the preview shows the venue selected on the ticket, and the built-in layout prints it below the date.

### Mails and customers
- Tickets and invoices are only marked as sent when the mail actually went out. A failed mail is noted in the order history.
- A customer whose only waiting-list signups have already been turned into orders can now be deleted; those signups are removed with them.

### Documentation
- New pages: Getting started (including the new menu item types), Control Panel, Email templates, Automatic tasks, Venues/customers/transactions, and Personal data.

## Check before you update
- **Built-in ticket layout:** tickets that use the built-in layout without their own field positions now also print the venue, and the fields below the date move down slightly. Check a ticket preview if you rely on that layout.
- **Menu items:** if the *Show Upcoming events* item wasn't your first Ticketstation menu item, the addresses and module assignments of the shop pages change to those of *Show Upcoming events*. Check any links you added to these pages by hand, and which modules show on them.
