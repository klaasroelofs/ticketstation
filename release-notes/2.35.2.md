## What's new in 2.35.2

### Changed
- **"Reservation" is now "Booking" in the English backend.** The tool for phone and walk-in orders is called *New booking*: in the Ticketstation menu, in the Box Office toolbar and on the control panel, where the button now names the action instead of the plural *Reservations*. The steps, messages, the *Make bookings* permission and the Documentation page use the same word. The tool creates a regular order that is paid straight away or saved as not yet paid, so "booking" fits both better than "reservation".
- **Dutch keeps "reservering".** Only the control panel button changed, from *Reserveringen* to *Nieuwe reservering*.
- **On the website, seats are still "reserved".** The customer's message while a seat is held in the cart has not changed.
