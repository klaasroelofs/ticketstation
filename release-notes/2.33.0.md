## What's new in 2.33.0

### Your company on the ticket
- **Your logo on the default ticket layout.** The *Company Logo* you choose in the Configuration is now also printed at the top of every ticket that uses the default layout. Without a logo, or when the file can't be used, the Ticketstation logo stays. Use a JPG, PNG or GIF.
- **Your own colour.** The new *Company colour* setting gives the bars and the ticket name on the default ticket layout your colour. A colour that is too light to read on white is not used for the ticket name. Tickets with a design of their own (uploaded under Tickets) are not changed.
- **The Company Logo moved** from the tab Documents to the tab Company, next to the colour. The invoice still uses it, and shows the Ticketstation logo when the chosen file is gone, instead of no logo at all.

### Fixed
- **Joomla's database check is clean again.** *System, Maintenance, Database* no longer reports the temporary transactions' `provider` column, and the update repairs that column on sites where it had another definition.

### Cleaned up
- **Settings nothing used are gone.** The Configuration table lost 31 columns that were technical debt: ticket layout positions and barcode sizes (these are set per ticket), Mailchimp, redirects after login, and some invoice and download switches. Nothing in Ticketstation read them.

## Check before you update
- **Only if you have your own code or reports that read the Ticketstation configuration table** (`#__ticketstation_config`): the 31 removed columns are `bar_position`, `barcode_1d_x`, `barcode_1d_y`, `barcode_2d_x`, `barcode_2d_y`, `barcode_type`, `company_logo_position`, `create_invoice`, `currencytype`, `date_position`, `downloadid`, `free_text1_position`, `free_text2_position`, `hide_invoice_msg_cpanel`, `invoice_eid`, `invoice_logo`, `location_position`, `mailchimp_api`, `mailchimp_listid`, `name_position`, `orderid_position`, `payment_email_send`, `position_logo_confirmation`, `position_seatnumber`, `price_position`, `redirect_after_login`, `redirect_after_registration`, `scan_api`, `send_confirmation_pdf`, `show_downoad_button_in_myorders` and `show_mailchmp`. Everything you can set in the Configuration keeps working.
