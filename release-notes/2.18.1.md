## What's new in 2.18.1

### Licenses of the bundled libraries
- **Every PHP file now states its license.** Ticketstation bundles a few open-source libraries (for payments, QR codes and PDF files). Their files now carry a line naming their license (MIT or BSD-2-Clause, both compatible with the GPL), so the license of each file is clear on its own.
- **A list of the libraries.** The package contains a `THIRD-PARTY-NOTICES.md` file with the name, version, license and source of each library.
- **A smaller package.** Command-line scripts, documentation and code generators of the Mollie library that Ticketstation never uses are no longer installed.

Nothing changes in how Ticketstation works.
