## What's new in 2.7.2

### Ticket layout
- **The layout editor shows your ticket's own texts.** Instead of sample text, the editor and the preview now show the event name, ticket name, free text, start date, price, venue and codes as they are filled in on the ticket, including changes you haven't saved yet. You can see right away whether a long name still fits. Details that only exist once someone orders, such as the customer's name, the order date and the seat number, still show sample text.
