## What's new in 2.30.0

### New
- **Test data and live data are kept apart.** Every order, payment, invoice, customer and waiting-list signup now remembers whether it was made in test mode or live. In test mode the Box Office, Transactions, Invoices, Customers, Waiting list, the sold figures of events and tickets, and the control panel only show test data; when the shop is live they only show live data. A notice at the top of those screens tells you when you are looking at test data.
- **Delete test data.** When there is test data, the control panel shows how much next to the **Shop mode** switch, with a **Delete test data** button (Administrators only). It deletes the test orders with their tickets, payments, invoices and refunds, the test customers and the test waiting-list signups. Live data is never touched. You can also keep the test data: it stays hidden while the shop is live.
- **Test orders no longer touch the live shop.** A test order does not use up live tickets, seats or coupons, and a refund of a test order does not show up under *Needs attention* when the shop is live. When you switch the shop to live, the seats held by test orders become free again; the orders keep their seat number.
- **Test invoices have their own numbers.** Invoices made in test mode are numbered `TEST-00001`, `TEST-00002`, and so on, so you can try out invoices without leaving a gap in your live invoice numbers. Invoice numbers now come from a counter that never goes down, so the number of a removed invoice is not given to another invoice.
- **A payment follows its order.** A payment is always handled in the environment its order was made in. A test payment that is reported after you switched to live still completes its test order, a live order can never be paid with test money, and refunds of a test order go to the provider's test environment.
- **Customers are kept apart too.** The same email address is a separate customer in test mode and live, so test customers never end up in your live customer list.

### Improved
- **Mails about a test order** start with `[TEST]` in the subject.
- **The ticket scanner** refuses a test ticket while the shop is live, and a live ticket while the shop is in test mode, with a clear message.
- **Documentation.** The Test mode topics describe how test and live data are kept apart.

## Check before you update

- **Existing orders count as live,** except orders whose tickets carry the fixed test code from earlier test mode. If the shop is in test mode while you update, orders that are already there stay live; delete earlier test orders in the Box Office, or switch to *Live* first.
- **Live order numbers can have gaps.** Test orders use the same order numbers as live orders, so the live numbers skip the ones used by test orders.
