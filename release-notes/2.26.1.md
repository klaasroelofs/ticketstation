## What's new in 2.26.1

### Fixed
- **Joomla's *Database* check no longer reports problems about the old Mollie table.** Version 2.26.0 removed the unused table `#__ticketstation_mollie`, but Joomla's check still read the old update files that changed that table and reported it as missing. Those steps no longer run, so after this update *System* > *Maintenance* > *Database* shows no problems for Ticketstation. Nothing needs to be done on your side.
