## What's new in 2.21.0

### Mail the buyers of an event
- **Tell everyone who bought a ticket.** Select an event in the Events list and click *Mail the buyers*. Every order with paid, valid tickets for that event gets one mail, however many tickets it holds. Unpaid, refunded and released orders are skipped, and the screen shows how many orders the mail goes to.
- **Start from a suggestion.** Buttons fill in a subject and text for a new start time, another location or a cancelled event. You change the text, send yourself a test first, and then send it to everyone. For a cancelled event the screen points to the Box Office, where you can refund the orders.
- **Your own wording around it.** The mail is built from the new template *Message to buyers of an event* on the Templates screen, with `{message}`, `{subject}`, `{eventname}`, `{eventdate}`, `{eventtime}` and `{location}`.

### Reminder before the event
- **An automatic reminder mail.** Switch on *Send a reminder before the event* in the Configuration (Orders tab) and choose how many hours before the start it goes out (24 by default). The mail has the time, when the doors open, the place, a link to have the tickets sent again, and a calendar file. Every order gets it once per event and start time. Orders placed inside the reminder period get none, as they have just received their tickets.
- **It runs as a Joomla Scheduled Task.** Ticketstation now includes a task plugin. Create the task *Ticketstation reminders* under System, Scheduled Tasks and let it run hourly. The wording comes from the new template *Event reminder*.

## Check before you update
- **The reminder is off after the update.** Nothing is sent until you switch it on in the Configuration and create the Scheduled Task.
- **The two new mail templates have English texts.** Open *Message to buyers of an event* and *Event reminder* on the Templates screen and write them in the language of your customers.
