Raleway and Open Sans, latin subset, weights 400 and 700, from the npm packages @fontsource/raleway and @fontsource/open-sans 5.3.0 (SIL Open Font License 1.1, see the LICENSE files).
Used by the ticket layout editor to show the same typefaces as the ticket PDF.

pdf/ holds the same two typefaces for FPDF (TrueType, compressed .z, with JSON font definitions converted from the definitions made with FPDF's makefont), used in the ticket PDF itself (see Pdf::fontFile()).
